Factories run after rendering services initialize and before recording draws.

working directory stable during the manager's lifetime. No blanket lowercasing
is applied to paths, so case-sensitive directories are not conflated. Alternate

## Texture and shader contracts

```cpp
const Engine::Base::TextureLoadOptions dataTexture{
    Engine::Base::TextureColorSpace::Linear,
    Engine::Base::TextureMipMode::Preserve};
textures->LoadTexture(path, dataTexture);
auto srv = textures->GetSrvHandleGPU(path, dataTexture);
sprite->SetTexture(path, dataTexture);
```

Omitted options keep existing behavior: WIC is sRGB, DDS retains its encoded
format, UI files skip mip generation and other supported files request four mips
with fallback. Preserve retains authored mips (it does not strip DDS to one mip).
Explicit Generate requests a full chain for uncompressed textures and reports
failure instead of silently falling back. Compressed DDS must use Preserve or
Automatic. Explicit color space changes interpretation, not the source pixels.
Memory/RGBA uploads retain their existing bool mip argument; file options cannot
be applied to their opaque keys. Model materials keep their existing defaults.

ShaderCompiler is used on the existing setup/render thread. Cache hits still pay
for file reading and preprocessing; they avoid the full compile, not all I/O.
GetCompileCount counts full compilation attempts, GetCacheHitCount counts reuse.
There is no automatic live shader/PSO replacement, cross-process disk cache or
performance speedup claim from these correctness checks.
