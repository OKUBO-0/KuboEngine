# Octopus

`Octopus` は、敵を倒して経験値を集め、レベルアップで武器や能力を強化しながら生き残る 3D サバイバルシューティングゲームです。

プレイヤーはフィールド上で敵を避けながら戦い、経験値オーブを集めて成長していきます。レベルアップ時には 3 つの候補から強化を選び、通常弾、旋回弾、弓、ソード、雷、炎、オーラなどの武器や、攻撃力・最大 HP・移動速度などの能力を組み合わせて戦い方を作ります。

ゲームはタイトル、ゲームプレイ、リザルト、ショップで構成されています。プレイ中に獲得したポイントはショップで使うことができ、次回以降のプレイを有利に進められます。

## 操作

| 操作 | キーボード | マウス | ゲームパッド |
| --- | --- | --- | --- |
| 移動 | `WASD` / 矢印キー | 左クリック長押し | 左スティック / D-pad |
| 照準 | マウス照準 | カーソル方向 | 右スティック |
| 回避 | `Space` | 右クリック | `B` |
| 決定 | `Enter` / `Space` | 左クリック | `A` |
| 戻る / キャンセル | `Esc` | 右クリック | `B` |
| ポーズ | `Esc` / `P` | 中クリック | `Start` / `Back` |

## 制作内容

本作は C++20 と DirectX 12 で制作しています。描画、入力、音声、モデル読み込み、パーティクル、シーン管理などのゲームエンジン部分も自作し、その上にゲーム固有のプレイヤー、敵、武器、HUD、演出、レベルアップ処理を実装しています。

ゲームバランスや UI 配置は CSV で管理しており、武器性能、敵の出現、レベルアップ候補、プレイヤー初期値などをデータ側から調整できるようにしています。
